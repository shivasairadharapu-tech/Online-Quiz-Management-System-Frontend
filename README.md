# 🎯 QuizMaster - Frontend

Frontend for the Online Quiz Management System built with **React 18**, **Vite**, and **React Router**.

---

## 🌐 Live Application
👉 **[https://online-quiz-system-backend-1.onrender.com](https://online-quiz-system-backend-1.onrender.com)**

---

---

## 🛠️ Tech Stack
- **Framework:** React 18
- **Build Tool:** Vite
- **Routing:** React Router v6
- **HTTP Client:** Axios with JWT Interceptors
- **Icons:** Lucide React

---

## 💻 Local Development
```bash
npm install
npm run dev
```
Runs at `http://localhost:5173` and proxies API requests to `http://localhost:8080`.
